DramaDex Workbench

Feed it a play → see what the parser understood → turn the knobs → watch the score. Nothing leaves this computer.

How you use this (3 steps):
  1. Load a play. Hit Try the sample play (Trifles is built in), or open any .txt script file.
  2. Read the middle pane like a marked-up script. Purple bold = who's speaking. Gray italic = stage directions. Yellow = the parser isn't sure. Green underline = a prop it spotted. Click any line to see everything the parser extracted from it.
  3. Turn knobs on the right, watch the score. When a parse looks fully correct to you, press Save as answer key. From then on, every knob change or new rule shows a live accuracy % against your checked version - up means better, down means you broke something.
  4. Zoom in when something looks off. The filter bar above the script isolates one character's lines or one issue type (unsure rows, prop hits, monologues). And Pin snapshot freezes the current parse so that when you change exactly one knob, every line that changed lights up orange — a controlled experiment.
